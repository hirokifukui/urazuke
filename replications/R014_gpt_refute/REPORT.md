# 主張の検証（反証の試み）

資料の事実確認には、このフォルダの4つのPDFだけを用いた。頁は原則として本文の印刷頁とし、SIB本文は「印刷頁（PDF通算頁）」で示す。概要はいずれもPDF通算1頁。判定は主張全体に対するもので、資料の記述を正確に報告していることと、その記述が因果効果を十分に立証していることを区別する。

抽出は `pdftotext -layout`、計算はPythonのDecimalで実施した。再実行は `python3 verification/check.py`。抽出全文は `verification/*.txt`、該当頁は [excerpts.txt](verification/excerpts.txt)、計算結果は [calculations.txt](verification/calculations.txt)、コードは [check.py](verification/check.py) に保存した。以下の丸め計算は通常の四捨五入を仮定する算術的検証であり、資料に丸め規則が明記されているという意味ではない。外部情報は使用していない。

## Q1

**判定：支持**

### 確かめた箇所と値

- `shokugyo_report.pdf` 1頁「1(3) 職業訓練の効果検証上の課題」から2頁冒頭：編入条件として、訓練希望者のみからの選定、良好な受刑中の生活態度、健康状態に問題がないことを挙げ、編入に影響するバイアスの事前統制が必要と記載。
- 同2頁「3(2) 方法」、脚注2・3、および「3(3) 結果」から3頁図1：ロジスティック回帰分析で特定し、傾向スコアマッチングで統制した項目は、出所時年齢、刑事施設への入所回数、出所時の制限区分、能力検査値の4つ。訓練希望と健康状態は、この統制項目の列挙に含まれない。
- 同3頁図1・図2と本文：修了群・非修了群は各2,218名。保護観察終了時の有職率はそれぞれ78.7％・74.0％（差4.7ポイント）。本文は「安定した就労を継続している者の割合が高い」と記載。
- 同5頁「5 結論」末尾：「職業訓練は、出所後の安定的な就労に寄与」と記載。主張に挙げられた数値・記述はいずれも一致する。

### 別の説明

資料自身が1頁で挙げる訓練希望・健康の差は、明示された4項目では直接統制されていない。ただし、資料にはこれらと4項目との関連の程度が示されておらず、間接的にも一切調整されないとまでは確かめられない。

また、`shokugyo_gaiyou.pdf` 1頁「検証1」は、非修了者群に職業訓練途中離脱者を含むと明記する。比較は単純な「訓練を受けた者対まったく受けなかった者」ではない。本文2頁の対象は、2019年の仮釈放者のうち2021年3月末までに保護観察を終了し、必要データに欠損がない者に限定される。

### 言い過ぎの指摘

Q1は本文がそう書いているという報告として支持できる。一方、本文2～3頁で示される測定は保護観察終了時の有職の有無であり、就労期間・離転職履歴などの継続性の測定は示されない。「安定した就労の継続」を直接確認したとの読み方は強すぎる。

一般的な統計上の性質として、傾向スコアマッチングは、用いた変数での調整によって未測定の交絡まで自動的に除去するものではない。有意差（本文3頁脚注5：有意水準5％）だけで、選抜の影響がすべて解消したことや因果効果が確定したことにはならない。

## Q2

**判定：判定不能**

数値・引用の大半は確認できる。しかし「本文に支援対象者の再処分率の分母は書かれていない」という部分は、評価対象者の定義を分母の記載とみなすか、実際の算出人数の明記を求めるかで結論が変わる。指定された規則に従い、主張全体を支持とはしない。

### 確かめた箇所と値

| 確認事項 | 箇所と読んだ値 |
| --- | --- |
| 再処分率と定義 | `sib_report.pdf` 14頁（PDF16頁）「3(2)イ③」：比較対照群8.7％、支援対象者5％、対照群100に対して57。再処分率は「再非行・再犯により保護処分又は刑事処分を受けた者の人員の占める比率」。 |
| 対照群の人数・範囲 | 同13頁（PDF15頁）図表7：2021・2022年に全国の少年院を出院し、出院後の進路が進学・復学希望の者379人。同14頁は「出院して保護観察を開始した者」とも記す。 |
| 評価・支払 | 同15頁（PDF17頁）図表8の2023年度アウトカム指標③：結果5/8.7、成果57％、評価A、支払割合100％。同9頁（PDF11頁）図表5では、対照群比70％未満がA・100％。 |
| 支援対象者数 | 同6頁（PDF8頁）「イ 支援期間等」：当初約80人、結果29人。`sib_gaiyou.pdf` 1頁「対象者」も29人。 |
| 支援側の参加条件 | 本文5頁（PDF7頁）図表4、6頁（PDF8頁）の決定手順：本人の学習支援希望、東京保護観察所管内（立川支部除外）又は大阪保護観察所管内（堺支部除外）への帰住予定、少年と保護者の同意など。概要1頁も希望・東京又は大阪・保護者の同意を列挙。 |
| 因果関係の評価という記載 | 概要1頁右下：非対象の修学希望者を事業がなかった場合の仮想の結果として比較し、「因果関係の評価が行われた」。本文23頁（PDF25頁）「(5) 評価方法」にも同趣旨。 |
| 少人数の限界 | 本文24頁（PDF26頁）：「29人」「統計分析を行うには過少」「誤差の少ない評価を行うことは困難」。 |

29人を分母とする単純比率について、1/29×100＝3.448…％、2/29×100＝6.896…％。分子を0～29の整数で全探索しても、通常の整数％への四捨五入で5％となる人数はない。小数1桁で5.0％となる人数もない。この算術的指摘は正しい。

ただし、本文13頁（PDF15頁）図表7の再処分率行には、**評価対象者が「2021年度、2022年度、2023年度の支援対象者合計」**と書かれている。分母を推測する材料が全くないわけではない。他方、14～15頁の結果は5％と5/8.7であり、「再処分人数／算出対象人数」という実人数の組は記載されない。全文の確認でも、再処分率について除外者・実際の算出人数を特定する説明は見つからない。

対照群の定義には、支援側の地域・学習支援への参加希望・保護者同意は要件として列挙されていない。この記載上の差は確認できるが、対照群各人がそれらの条件を満たさないとまでは分からない。

### 別の説明

本文14頁（PDF16頁）脚注9・10は、他の成果指標について、途中終了等による除外を明示する。目標達成率は17/23、YNPSスコアは16/20であり、全支援対象者29人と指標の算出対象人数は必ずしも一致しない。したがって、再処分率も対象の絞り込みがあった可能性は排除できない。ただし、この除外規則を再処分率にも適用したとは書かれていない。YNPSの20人を再処分率の分母として、1/20＝5％だったと断定することもできない。

「分母は書かれていない」を「5％の算出に使った実人数が明記されていない」の意味に限れば裏付けられる。一方、評価対象者合計の定義も分母の記載に含めるなら、その断言は弱まる。解決には、再処分人数、実際の算出対象人数、除外条件、観測期間・丸め方法の明示が必要である。

本文23頁（PDF25頁）は、傾向スコアマッチング等による対照群抽出が厳密性の観点から望ましかったこと、学習支援以外の要因も想定されることを述べる。概要の因果関係評価という記述だけを取り出すと、この留保を落とす。

### 言い過ぎの指摘

29人と5％の組合せには説明を要するが、これだけで5％が誤りとは確定できない。57は対照群比であり、支援群の絶対的な再処分率57％ではない。5/8.7×100＝57.471…なので、57という整数表示とは整合する。

支払割合100％は当該指標の契約上の評価結果であり、因果効果の確実性を表す値ではない。一般的な統計上の性質として、参加条件の異なる非無作為の比較では、選択の差や他の支援による交絡があり得る。ただし、それが今回の差のすべてを説明するとの断定も資料からはできない。

## Q3

**判定：反証**

### 確かめた箇所と値

`shokugyo_report.pdf` 4頁表2「職業訓練種目別の有職率及び一致率」の溶接科は、修了人数139人、有職率86.3％（120人）、一致率56.8％（79人）。

```text
79 / 139 × 100 = 56.834532374101…％ → 小数1桁で56.8％
```

主張の「合わない」に反し、79人と139人は掲載の56.8％と整合する。`shokugyo_gaiyou.pdf` 1頁の抜粋表も溶接科の一致率56.8％を掲載する。

### 別の説明

有職者120人を分母にすれば79/120×100＝65.833…％となるが、表2の一致率は修了人数を分母とする値と整合する。同4頁表1も450/2,575×100≒17.5％である。本文5頁結論が述べる「有職である職業訓練修了者のうち」の割合とは、分母を区別する必要がある。

表2の注記は、修了人数50人以上の種目のみ掲載し、複数種目を修了した場合は代表的な種目のみ掲載するとする。これは表の対象範囲に関する留保であり、この行の計算不整合を示すものではない。

### 言い過ぎの指摘

この数値から計算ミスを指摘することはできない。一方、この一致率だけで資格の実際の使用や訓練の因果効果まで確認したとはいえない。本文4頁で調査したのは取得可能な資格等と保護観察終了時の就労職種との対応である。

## Q4

**判定：反証**

### 確かめた箇所と値

`sib_report.pdf` 13頁（PDF15頁）図表7の対照群は379人、14頁（PDF16頁）「3(2)イ③」の対照群再処分率は8.7％。

```text
33 / 379 × 100 = 8.707124010554…％ → 小数1桁で8.7％
分子を0～379の整数で全探索：小数1桁で8.7％になる分子は [33]
```

「どの整数人数でも…ならない」という主張は、33人という反例で反証される。

### 別の説明

8.7％を丸め前の厳密値とみなせば379×0.087＝32.973人で整数にならない。しかし、Q4は小数1桁表示についての主張であり、通常の丸めを考慮すれば矛盾はない。資料は再処分人数33人を直接記載しているわけではないため、33人は379人を分母とした単純比率・通常の四捨五入という前提での逆算値である。

### 言い過ぎの指摘

小数表示を丸め前の厳密値と扱って不整合とするのは誤りである。ただし、この計算の整合性は、対照群の妥当性や因果推論の十分性、Q2の支援群5％の算出方法まで保証しない。

## 全体の要約

Q1は支持：本文の条件・調整項目・人数・有職率・結論の記述は一致するが、継続就労と因果効果の解釈には限界がある。  
Q2は判定不能：主要な数値と留保は確認できるが、「分母の記載」の意味に幅があり、5％の実際の算出人数は特定できない。  
Q3・Q4は反証：79/139は56.8％、33/379は8.7％に丸められる。
