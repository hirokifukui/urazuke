# 引用の型の判定

| 組 | 型（複数可） | 根拠 |
|---|---|---|
| C01 | T4 | 「約1300人」と「推計」は元の文と一致するが、「認知症傾向」をHDS-Rの得点が20点以下とし、医師の診断の有無で区別しないという限定が省かれている。 |
| C02 | T4 | 「約14％」は元の文の「およそ14％」と一致するが、見出しにはHDS-Rの得点が20点以下という基準と、医師の診断の有無で区別しないという限定がない。 |
| C03 | T3、T4 | 「推計」は残るが、「およそ1,300人」「およそ14％」の概数表現が落ち、「1,300人」「14％に上っています」と言い切っている。HDS-Rの得点基準と医師の診断に関する限定も省かれている。 |
| C04 | T0 | 「令和5年度」と「2023年度」は同じ年度で、「225,509件」と「22万5509件」は同じ対応件数を表す。 |
| C05 | T1 | 同じ2023年の小中高生の自殺者数が、元の文では「513人」、引用では「531人」になっている。 |
| C06 | T4。「2015年6月時点」の一致は判定不能 | HDS-Rの得点基準と医師の診断に関する限定が省かれている。「認知症傾向が認められた」は引き続き「認知症傾向」を述べており、元の文にある調査時期・対象者の基準日・公表月からは、推計値の「2015年6月時点」が正しいか判断できない。 |

認知症傾向を引いた4組では判定基準の限定が省かれ、C03では概数表現も落ちている。  
C04の件数は一致し、C05の人数には差がある。  
提示文から、掲載前に訂正があったかは確認できない。
