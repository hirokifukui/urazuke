# R031 採点

対照：CTRL-T0 → T0、CTRL-T1 → T1。両方正答。この回を採る。

| 組 | 型 | 根拠（別系統の文） |
| --- | --- | --- |
| P-NK-01 | T4 | 「約14％」は元の文の「およそ14％」と一致するが、見出しにはHDS-Rの得点が20点以下という基準と、医師の診断の有無で区別しないという限定がない。 |
| P-NK-02 | T3、T4 | 「推計」は残るが、「およそ1,300人」「およそ14％」の概数表現が落ち、「1,300人」「14％に上っています」と言い切っている。HDS-Rの得点基準と医師の診断に関する限定も省かれている。 |
| P-NK-03 | T4 | 「約1300人」と「推計」は元の文と一致するが、「認知症傾向」をHDS-Rの得点が20点以下とし、医師の診断の有無で区別しないという限定が省かれている。 |
| Q-NK-K1-001 | T4。「2015年6月時点」の一致は判定不能 | HDS-Rの得点基準と医師の診断に関する限定が省かれている。「認知症傾向が認められた」は引き続き「認知症傾向」を述べており、元の文にある調査時期・対象者の基準日・公表月からは、推計値の「2015年6月時点」が正しいか判断できない。 |

Q-NK-K1-001 は R029 の判定（T0）をこの回の判定で置き換える。R029 では元の資料の文に定義（HDS-R 20点以下、医師の診断によらない）を含めていなかった。「2015年6月時点」の部分は別系統が判定不能とした。
