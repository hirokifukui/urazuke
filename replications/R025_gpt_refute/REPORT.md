# 公的統計の主張の検証

資料の事実は提供ファイルで確認した。PDFは `pdftotext -layout` で抽出し、頁はPDFの先頭から数えた。ExcelはPythonの `zipfile` と `xml.etree.ElementTree` でシート名・セル番地・保存値を読み、CSVは `csv.reader` でShift_JISとして読み込んだ。HTMLはソースの見出し、表、本文を検索して確認した。CSVの行番号は先頭を1とする。

- **別の説明**　年度別の `r5_zennkoku_nyuuinnryou__r5_zennkoku_nyuuinnryou_keitai.xlsx` と `r6_zennkoku_nyuuinnryou_keitai.xlsx` の「全国」G3には「不明」があり、合計G24・G25はそれぞれ475人・382人。両年とも総数と4区分も長期表と一致し、「不明」を足すと総数に合う。
- **言い過ぎの指摘**　全国で4区分の和が総数を下回るのは、提示された期間では2018～2025年。年度別表で差を「不明」で説明できたのは2023・2024年で、2018年の955人の内訳はこの照合だけでは確定できない。

## Q5　回答率と在院患者数の落ち込み

- **判定**　支持。例示された3地域・年とその隣接年の比較として確認した。
- **確かめた箇所と値**　年度別の従来集計ブックのシート「1.1」で、C列の回答病院数をD列の配布数で割り、E列と照合した。在院患者数は `longterm_1998_2025.xlsx` の同名シートから抽出した。

- **確かめた箇所と値（続き）**　長期ブックの全56シートの名前とセル文字列、および「目次」B69:C71の注を確認し、回答率の列や回答率についての注は見当たらなかった。
