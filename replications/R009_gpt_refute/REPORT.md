判定対象は、このフォルダに保存された資料。外部サイト・記憶による補完は行っていない。単位は検察第1表が件、第2表が人、決算カードが千円。

抽出・再計算は `verify.py` と `calculations.py`、結果は `evidence/` に保存した。実行環境に openpyxl がなかったため、Excel は Python 標準の zipfile・ElementTree で XLSX 内のシート対応・共有文字列・セル値を直接抽出した（ふりがな要素を除去）。HTML は HTMLParser で script/style とタグを除いた本文、および href を抽出。PDF は `pdftotext -layout kensetsu_R06nendo_press.pdf evidence/kensetsu_R06nendo_press.txt` で抽出した。再実行は `python3 verify.py`、`python3 calculations.py`。主要な算術結果は `evidence/calculations.txt`、第2表の全年比較は `evidence/kensatsu_checks.csv` に残した。

## Q4

**判定：支持。** 保存されたHTMLの範囲での判定。

**確かめた箇所と値：** `kensetsu_press_R06nendo.html` の【参考】段落（原HTML 71～73行）は令和8年6月12日の差替を明記し、「差替前と比較した新旧表はこちらをご覧下さい。」とする。「こちら」の href は `https://www.mlit.go.jp/sogoseisaku/jouhouka/sosei_jouhouka_fr4_000033.html`。保存された `kensetsu_shusei_page.html` のタイトル・見出しは「情報化：修正情報」／「修正情報」。本文全体と全リンクを抽出したところ、最新日付の項目は「令和７年６月３０日訂正公表」であり、令和8年6月12日の項目も、それに対応する新旧表リンクもない。本文とリンク一覧は `evidence/kensetsu_shusei_page.txt` および同 `_links.json`。

**別の説明：** 修正情報ページに新旧表が一切ないわけではない。令和6年7月12日発表の項目には【新旧（新旧表）】と10本のリンクがある。最新の令和7年6月30日項目は大手50社調査の施工高・手持ち工事高に関するもので、報道発表ページの甲調査の取込み漏れ等とは説明内容が異なる。報道発表ページには訂正後統計表を国交省HP・e-Statに掲載したとの記載もある。

**言い過ぎの指摘：** 言えるのは保存されたリンク先ページ内で対象項目・新旧表を確認できないことまで。新旧表が他の場所にも存在しない、あるいは訂正が行われていないとは言えない。リンク先の別PDFはフォルダにないため内容を推測していない。
