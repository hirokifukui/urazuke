# 犯罪白書の主張の検証

提供された Excel 13点と訂正のお知らせの HTML 1点を対象とした。判定は主張全体に適用し、一項目でも資料と矛盾すれば「反証」、確認できた部分に矛盾がなく残りに必要な資料がなければ「判定不能」とした。下のファイル名は共通の先頭部分 `hanzai_hakusho__` を省略した。版番号は66が令和元年版、68〜72が順に令和3〜7年版。

Excel は Python の `openpyxl.load_workbook(..., data_only=True)` で全シートを読み、セル座標と保存値を抽出した。行の対応付け、列の突合、集計、比率の再計算も Python で行った。HTML は `html.parser.HTMLParser` で本文を抽出した。率は百分率で記載し、比較には丸め前の値を用いた。
