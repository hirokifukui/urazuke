# 公表資料に基づく主張の検証

警察庁の3資料は `pdftotext -layout` で全頁を抽出し、改頁（フォームフィード）でPDF頁を特定した。職業訓練論文の表と本文は、対応する提供画像から読み取り、転記した値をPython 3で集計・検算した。頁はPDFの先頭を1頁とし、論文については印刷頁も併記する。

## Q1

**判定　支持**

- **確かめた箇所と値** — `kentokai1_shiryou3.pdf` 3頁（資料3-3）「加害者対策に係る現行の施策とその課題」の右欄、第1項。令和4年7月から令和7年6月までの3年間に禁止命令等を受けた6,548人のうち497人が再発とされる。497 ÷ 6,548 × 100 は約7.590％で、記載の約7.6％と一致する。続く本文は、大多数が禁止命令等によってその後ストーカー行為等を行わず、1割弱では命令等のみで十分な再発防止効果が得られていないと述べる。同頁下の注が数えるのは、命令等の期間中に、同一被害者に対し、つきまといによって再度ストーカー規制法の罪に当たる行為をした場合である。期間終了後、別の相手に対する行為、同法の罪に当たらないつきまといは、この集計から外れる。
- **別の説明** — `kentokai1_shiryou3.pdf` 2頁（資料3-2）には、警察が危険性・切迫性を評価し、検挙措置や、法の要件に該当する場合の禁止命令等で対応するとある。3頁左欄には受診等勧奨も記載されている。命令を受ける人の選ばれ方や併行する措置も、観察された割合の解釈に関わる。
- **言い過ぎの指摘** — Q1の指摘どおり、資料本文の「その後ストーカー行為等を行うことはない」は注で測った範囲を超える。比較の有無は `kentokai1_shiryou1.pdf` 全2頁、`kentokai1_shiryou3.pdf` 全6頁（資料3-1〜3-6）、`kentokai1_gaiyou.pdf` 全5頁で確認した。発出件数の推移や委員の意見はあるが、命令等を受けなかった者の再発と比較した結果は示されていない。統計の一般論として、命令を受けた集団の観察割合だけでは、命令によって再発がどれだけ減ったかは推定できない。

## Q3

**判定　支持**

- **確かめた箇所と値** — `shokugyo_2025.pdf` 8頁（印刷45頁、`shokugyo_pages/pg-08.png`）表6「犯罪傾向の進度」の人数・％欄は、希望ありAが702人（32.1％）、Bが1,484人（67.9％）で、合計2,186人。希望なしAは1,484人（27.8％）、Bは3,852人（72.2％）。希望ありBと希望なしAの印字人数は同じで、χ²欄は48.046。同頁の表5「出所時年齢」「懲罰回数」の希望あり人数はいずれも1,937人。6頁（印刷43頁、`shokugyo_pages/pg-06.png`）表1の男性・希望ありの人数も1,937人。
- **確かめた箇所と値（表10と再計算）** — 同PDF 10頁（印刷47頁、`shokugyo_pages/pg-10.png`）表10の同項目は、実施ありA 149人・B 161人、実施なしA 553人・B 1,074人。合算するとA 702人・B 1,235人。希望なしのセルを固定し、希望ありBを1,235人とした2×2表のPearsonのχ²（連続性補正なし）は48.045805（小数第3位までで48.046、第2位までで48.05）。印字どおり1,484人とすると13.923415（同13.92）。
- **別の説明** — 表5では項目によって集計人数が異なり、希望ありの入所度数は1,818人、能力検査値は1,742人。したがって、項目別人数と群全体の人数との差だけなら集計対象の違いも考えられる。ただし、この項目では表6の合計が群全体を249人上回り、表10から同じ項目を再集計すると群全体の1,937人に一致する。表6の印字割合32.1％・67.9％自体は印字人数の合計2,186人に整合する。表10から再集計した人数では36.2％・63.8％になる。
- **言い過ぎの指摘** — 表間の照合とχ²の再現は、希望ありBが1,235人だったという推定を支える。希望なしAからの転記が原因だったかは、値の一致だけでは確定できない。

## Q4

**判定　反証**

- **確かめた箇所と値** — `shokugyo_2025.pdf` 10頁（印刷47頁、`shokugyo_pages/pg-10.png`）表10「犯罪傾向の進度」の「職業訓練の実施あり」人数・％欄では、**Aが149人（48.1％）、Bが161人（51.9％）**。149 ÷ 310 と161 ÷ 310を百分率に直すと、丸めた値がそれぞれ一致する。
- **別の説明** — 主張の人数と割合は、同じ列の直下にあるBのセルに一致する。また、9頁（印刷46頁、`shokugyo_pages/pg-09.png`）の「④職業訓練実施あり群の特徴」は、希望あり群を実施の有無で分けると説明している。
- **言い過ぎの指摘** — Aの割合は実施なし群の34.0％より高いが、実施あり群内では48.1％で半数未満である。群間で割合が高いことと、その群の過半数を占めることは別である。

## 計算の再現

抽出は警察庁資料ごとに `pdftotext -layout "$f" "${f%.pdf}.txt"` を実行し、抽出テキストを `split("\f")` で頁に分けた。以下は画像からの転記値と抽出値を用いた検算。χ²の式は統計の一般知識による。

```python
def pearson_chi2(a, b, c, d):
    total = a + b + c + d
    margins = (a + b) * (c + d) * (a + c) * (b + d)
    return total * (a * d - b * c)**2 / margins

print(100 * 497 / 6548)  # 7.5901038...
print(702 + 1484, 149 + 553, 161 + 1074)  # 2186, 702, 1235
for b in (1937 - 702, 1484):
    print(f"{pearson_chi2(702, b, 1484, 3852):.6f}",
          [round(100 * count / (702 + b), 1) for count in (702, b)])
# 48.045805 [36.2, 63.8]
# 13.923415 [32.1, 67.9]
print([round(100 * count / (149 + 161), 1) for count in (149, 161)])
# [48.1, 51.9]
```

Q2・Q4は反証。受診等につながった者は147人で、表10の実施あり群のAは149人（48.1％）。
