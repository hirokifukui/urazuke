# 課題：主張の検証（反証の試み）

このフォルダには、法務省の公表資料の写しがあります。
- kyosei/：矯正統計年報の Excel。2025年は全表（25-00-*.xlsx）、2020〜2024年は第88表（休養患者の病名別）・第93表（死亡者の病名別）。ファイル名は「年の下2桁-00-表番号」。
- hanzai_r04.pdf〜hanzai_r07.pdf：犯罪白書 令和4〜7年版（PDF）。
- hanzai_r06_web/：令和6年版犯罪白書の Web 版本文（HTML、2026-11-16 取得）。
- hanzai_r06_teisei.html：法務省「令和６年版犯罪白書の訂正のお知らせ」。
- saihan_r04.pdf・saihan_r06.pdf・saihan_r07.pdf：再犯防止推進白書 令和4・6・7年版（PDF）。

以下の主張は、ある検証者が書いたものです。**正しいものも、誤っているものも含まれています。**あなたの役割は、各主張をこのフォルダの資料に基づいて独立に確かめ、誤りがあれば見つけることです。検証者の結論に合わせる必要はありません。

## 判定の規則（先に固定する。これ以外の判定はしない）
- **支持**：主張の中の数値・事実を、資料の該当箇所（ファイル名・頁・表）で自分で確かめ、すべて一致した。
- **反証**：主張の中の数値・事実の少なくとも1つが、資料の該当箇所と矛盾する。矛盾する箇所と値を示す。
- **判定不能**：資料に確かめる材料がない、または解釈によって結論が変わる。何が足りないかを書く。

各主張について：1. 確かめた箇所と読んだ値、2. 主張を弱める別の説明（定義の違い、注記、別の箇所の記述など）を資料の中から探して挙げる、3. 言い過ぎがないか。計算・抽出はコードで行い（pdftotext -layout、openpyxl など）、要点を残す。資料の事実は資料だけで確かめる。統計の一般的な性質は知識として使ってよい。その場合は、そう明記する。

## 主張
- **Q1** 「訂正のお知らせ」は 12 か所を訂正している。そのうち Web 版本文（hanzai_r06_web/）で文言を特定できる箇所は、すべて訂正前の値のままで、訂正後の値になっている箇所はない。例：認知症スクリーニング検査の結果は「医師による診察を受けた者が312人、認知症と診断された者が125人」（訂正後は 313人・126人）、生活環境の調整を開始した受刑者 2万8,559人（訂正後 2万8,508人）、配偶者からの暴力事案等の相談等件数 女性 6万2,444件（訂正後 6万3,935件）。PDF（hanzai_r06.pdf）の該当箇所も訂正前の値。
- **Q2** 矯正統計年報 2025年の全表のうち、認知症またはアルツハイマー病の行があるのは、休養患者の病名別（第88〜91表）と死亡者の病名別（第93表）だけである。
- **Q3** 第37表（新受刑者の精神診断）には「認知症」の区分がある。
- **Q4** 第88表の「血管性及び詳細不明の認知症」（男）の総数は、2020〜2025年に 18・13・14・12・12・15人。
- **Q5** 認知症スクリーニング検査の結果は、次のとおり白書に載る。2018〜2021年（再犯防止推進白書 令和4年版 特2-1-4表）：実施 893・908・930・973人、診断 35・50・54・55人。2022年（犯罪白書 令和5年版）：実施 744人、診断 28人。2023年：実施 2,096人、診断は 犯罪白書 令和6年版 125人・再犯防止推進白書 令和6年版 126人。2024年（犯罪白書 令和7年版・再犯防止推進白書 令和7年版）：実施 2,086人、診断 132人。2023年から対象が全国の刑事施設・入所時65歳以上等に広がった。
- **Q6** Web 版本文（hanzai_r06_web/）の認知症スクリーニング検査の結果は「医師による診察を受けた者が313人、認知症と診断された者が126人」で、訂正後の値になっている。
- **Q7** 再犯防止推進白書 令和4年版は、高齢受刑者のうち認知症傾向のある者をおよそ17％、1,100人程度と推計し、出典を平成27年の法務省調査とする。2022年以降の白書は、スクリーニングの実施数・診断数と並べて、対象となった受刑者の総数を示していない。
