# 主張の検証（反証の試み）

このフォルダの資料だけを使用した。頁は原則として冊子の印刷頁とし、PDFの先頭を1とする通し頁を併記する。判定は質問に指定された3区分による。複合主張は、一部分でも明確な矛盾があれば「反証」、解釈によって結論が変わる場合は「判定不能」とした。

## 抽出・照合方法

PDFは `pdftotext -layout 入力.pdf evidence/入力.txt` で抽出し、改頁文字 `\f` で頁を分離した。検索時は空白を除去し、全角・半角を正規化した。HTMLはタグを除去して文字参照を復号した。ExcelはPython標準ライブラリの `zipfile` と `xml.etree.ElementTree` で各xlsxの共有文字列と全ワークシートのセルを読み、認知症・アルツハイマーを全件検索した。外部情報は参照していない。

再現用コードは [evidence/extract.py](evidence/extract.py) と [evidence/audit.py](evidence/audit.py)、主要な出力は [evidence/audit.txt](evidence/audit.txt)、Excelの抽出全体は [evidence/xlsx.json](evidence/xlsx.json) に残した。再実行はPDF抽出後に `python3 evidence/extract.py`、`python3 evidence/audit.py > evidence/audit.txt`。Excel内のふりがなが本文に続いて抽出される箇所があるため、引用ではふりがなを省いた。短い数値の別文脈での一致は根拠にせず、対応する文章で照合した。

**確かめた箇所と値**：[kyosei/25-00-37.xlsx](kyosei/25-00-37.xlsx) 第37表「新受刑者の罪名及び入所度数別 精神診断」のM5〜V5は、精神障害なし、知的障害、人格障害、神経症性障害、発達障害、精神作用物質使用による精神及び行動の障害、統合失調症、気分（感情）障害、その他の精神障害、不詳。**「認知症」の区分はない**。全セル検索でも該当しない。

**言い過ぎの指摘**：「区分がない」を「認知症の新受刑者がいない」と読み替えることもできない。
