# 主張の検証

PDFの頁は原則として本文の印刷頁を示す。頁番号のない資料ではPDFの頁を示す。PDFは `pdftotext -layout` で抽出し、改頁ごとに表と本文を照合した。XLSXはPython 3の `zipfile` と `xml.etree.ElementTree` でワークシートと共有文字列を読み、セル番地と格納値を取得した。

## Q1

**判定　支持**

**確かめた箇所と値**  
第1表は `kensatsu_r07_t01.xlsx` のシート `25-00-01`、第2表は `kensatsu_r07_t02.xlsx` のシート `25-00-02`。表の見出しに従い、Pythonで各年の行を走査した。受理は D と E+F、既済は G と第1表の H+I+J+K または第2表の H+I+L+M、未済は第1表の L または第2表の N と D−G を照合した。第2表では不起訴計 I と J+K も照合した。注記のある合算・内数・外数を確認し、欠測は計算対象から外した。大正7～12年など合算先が明示された「×」は、その内訳を重複加算せず検算した。

## Q4

**判定　判定不能**

**確かめた箇所と値**  
`kyosei_R02_report.pdf` 5頁表1で、迷惑行為防止条例違反は受講群81/1,444名（5.6％）、比較対照群82/324名（25.3％）。同報告の各表から全再犯を読み取った。

| 罪名 | 出典 | 受講群の全再犯／人数 | 比較対照群の全再犯／人数 |
|---|---|---:|---:|
| 強姦 | 10頁 表10 | 105/480 | 25/73 |
| 強制わいせつ | 11頁 表13 | 194/653 | 23/92 |
| 迷惑行為防止条例違反 | 13頁 表16 | 51/81 | 46/82 |
| 児童福祉法違反等 | 14頁 表19 | 22/176 | 6/36 |
| 残る3罪名を合算 | 8頁 表7から上の4行を差し引き | 22/54 | 23/41 |
| 全体 | 8頁 表7 | 394/1,444 | 123/324 |

Pythonで再計算した。各層を `(a,n,c,m)`（受講群の再犯数・人数、対照群の再犯数・人数）とすると、`R = sum(a*m/(n+m))`、`S = sum(c*n/(n+m))`。Mantel–Haenszelリスク比は `R/S = 0.926686`。統計の一般式を用い、対数分散を `sum((n*m*(a+c)-a*c*(n+m))/(n+m)**2)/(R*S)` として `exp(log(R/S) ± 1.96*sqrt(分散))` を計算すると95％信頼区間は0.783526–1.096004。粗リスク比は `(394/1444)/(123/324) = 0.718735`。丸めるとそれぞれ0.93（0.78–1.10）と0.72で主張と一致する。

8頁は罪名構成、犯罪傾向の進度、RAT得点等の群間差を挙げて単純比較を不適当とする。5頁の分析方法と9頁の表8・9に示された全対象者のCox回帰の共変量は受講の有無とRAT得点。26頁「全体における指導の効果」は全再犯・性犯罪再犯とも抑止効果が確認されたと述べる。

`kyosei_H24_report.pdf` 7頁表3の仮釈放率は65.0％（受講群）と37.8％（非受講群）。令和2年の矯正局報告は全33 PDF頁の本文・表・注記を対象に検索し、属性表と対象者設定を確認した。同じ群別仮釈放率は見当たらない。3頁では未受講で出所した536名から212名（25+64+61+25+37）を除き324名を比較対照群とする。除外した212名の理由は列挙されるが、残った324名の具体的な非受講理由やその分布は掲載されていない。

**別の説明**  
条例違反の全再犯率は、個別の再犯率が示された4罪名に限れば両群で最高。残り3罪名をまとめた第5層も受講群では条例違反より低く、対照群では 23/41 が 46/82 と正確に等しい。表1の残り3罪名には個別の再犯数がない。対照群の23/41が条例違反と同率なので、残り3罪名がすべて条例違反以下であるには全て同率である必要があるが、1名の層ではその率を取れない。

**言い過ぎの指摘**  
「最も高い」を公表された4罪名に限れば確認できるが、表1の全7罪名を指すなら、対照群では上記の整数条件から少なくとも1罪名が条例違反を上回る。比較範囲が明記されておらず、その解釈で結論が変わる。統計の一般論として、罪名で層別した累積リスク比と、時間を用いRAT得点を調整したハザード比は異なる量であり、この再計算からCoxの結果や因果効果は判定できない。また、全対象者での分析結果を受講者一人ひとりや全ての下位群に広げることはできない。25～26頁では平成24年版との対象者設定、再犯の定義、観察期間の違いが示されている。

## Q5

**判定　支持**

**確かめた箇所と値**  
保護局の `001318218.pdf` 3頁「3 方法」と4頁表5に示されたCox回帰の説明変数は、保護観察所でのコア・プログラム受講の有無とRAT得点。ハザード比は表の順に1.485と1.442。刑事施設のプログラム受講の有無はモデルに掲載されていない。保護局平成24年版 `001322889.pdf` PDF2頁「4 結論」は、刑事施設での受講の有無等を加味した分析を今後の課題に挙げる。

**別の説明**  
令和2年版3頁脚注4のRATは犯歴や犯行の反復性等を用いてリスクを査定する。本文の「刑事施設に収容」は再犯の把握条件の一つ。矯正局報告も別に存在するが、提供された保護局の本文・概要・平成24年版および矯正局の両報告には、同一対象者について両プログラムの受講の組合せと再犯を比較できる集計が見当たらない。

**言い過ぎの指摘**  
公表分析で効果を分けられないという範囲で妥当。統計の一般論として、刑事施設での受講を調整していないことだけで、保護局の推定値の偏りの方向や大きさは分からない。
