## 抽出・計算の要点

- PDFは `pdftotext -layout` で原本から抽出し、Pythonで改頁文字 `\f` を分割してPDF頁を取得した。HTMLはタグを除去し、全角数字を正規化して訂正箇所の見出しを数えた。
- Excelは Python の `openpyxl.load_workbook(path, data_only=True)` で保存値を読み、率は `100 * numerator / denominator`、押収量は `sum(ws[f"{col}{row}"].value for col in "EGIO")` で再計算した。Q1では通常モードでF列のセル型と表示書式も確認した。
- Q5は西暦をキーに各系列を比較した。Q6は都市名と年をキーにF7・F8の一致数を集計した。Q8は年列ごとに各シート72行目の4区分を合算し、在院患者数との差を計算した。
