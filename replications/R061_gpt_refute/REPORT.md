# 公表資料に基づく主張の検証

配布されたファイルのみを使用した。「頁」は特記しない限りPDFの先頭から数えた頁で、印刷頁が異なる場合は併記した。PDFは `pdftotext -layout` で頁ごとに抽出し、HTMLは見出し・リンク・表番号を検索した。Excelは `openpyxl.load_workbook(..., data_only=True)` で表題・ラベル・値・表示書式を読み、Pythonで合計、比、丸めを再計算した。犯罪白書の版は各取得フォルダの MANIFEST の取得元と図表目次の版名で照合した。

## Q5 学習支援SIBの再処分率5％

**判定：支持**

**確かめた箇所と値**　`moj_kensho2/sib_report.pdf` 15頁（印刷13頁）の評価表は、対象を2021〜2023年度の支援対象者合計、対照群を379人と記す。16頁（印刷14頁）の③は支援対象者5％、対照群8.7％、対照群を100とした指標57。17頁（印刷15頁）の「5/8.7」は率同士の比較である。26頁（印刷24頁）に支援対象者29人。本文・図表と `sib_gaiyou.pdf` 1頁を確認した範囲で、支援群の再処分人員と実際に率の計算に使った分母は明記されていない。

Pythonで0〜29人の `100 * n / 29` を列挙した。5％ちょうど、または通常の整数％への四捨五入で5％になる人数はない。1人は3.448…％、2人は6.897…％で、8.7％との差は小数第1位でそれぞれ5.3、1.8ポイント。対照群は379人を分母とし、小数第1位に丸めると8.7％になる唯一の整数が33人（33/379＝8.707…％）。33は資料記載の実数ではなく、公表値からの逆算である。

**別の説明**　報告書16頁の注10は、別指標のYNPSに限って測定対象が20人になった経緯を記す。仮に1/20なら5％になるが、再処分率に同じ20人を使ったことを示す記載は確認できない。26頁は、個々の支援内容と再処分の有無を結ぶパネルデータを取得できなかったと記す。

**言い過ぎの指摘**　1人・2人は分母を29に固定した感度の例であり、実人数の候補を資料で確認できたわけではない。公表率が対照群より低いことは確認できる。本文25頁（印刷23頁）の比較設計の留保もあり、この差から支援の因果効果は確定できない。

## Q9 再犯率0.67倍とハザード比

**判定：判定不能**

**確かめた箇所と値**　`moj_sexoffender/001466396.pdf` 1頁は受講群の再犯率を非受講群の0.67倍と表記する。報告書 `moj_sexoffender/001455506.pdf` 4頁の表4「性犯罪の再犯についての観測期間最終日の再犯率」は受講群15.1％、非受講群26.2％で、Pythonで割ると0.576335…（約0.58）。同頁の表5の多変量解析は受講の有無のハザード比1.485（95％CI 1.101–2.004）。3頁の結果本文は非受講が再犯を予測したと説明し、向きを反転した逆数は0.673400…で、丸めると0.67となる。

**別の説明**　3頁の方法・脚注7〜9は、観測期間が人によって異なり、観測期間を使った生存曲線、ログランク検定、RAT得点を入れたCox回帰を使ったと記す。表4は観測最終日の再犯率として掲載された値で、単純な「再犯人数÷各群の当初人数」とは資料から確認できない。表5は再犯に至っていない人の時点ごとの発生率を比較する指標で、最終日の累積割合の比とは推定対象が異なる（統計の一般的な性質）。

**言い過ぎの指摘**　「割合」を表4の観測最終日の推定値と読めば、0.58と0.67の数値比較は成立する。実際の再犯人数の粗割合と読めば、両群の再犯人員が必要になる。また、0.67と逆数の丸めは一致するが、概要にも報告書の該当箇所にもその算出式は明記されない。0.58のほうが小さいことは、同じ再犯指標でみた効果が大きいことを意味しない。非受講群に短期の保護観察などの除外事由があることも概要に明記されている。
