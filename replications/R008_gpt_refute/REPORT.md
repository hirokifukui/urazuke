# 資料内での主張検証

判定は提供ファイルだけに基づく。インターネットは使用していない。「支持」は提供された写しとの一致を意味し、公表元の原本との同一性まで保証しない。

抽出コードは `evidence/verify.py`、主張別の集計は `evidence/check_claims.py`、実行結果は `evidence/check_results.txt` に保存した。Python 3 の標準ライブラリ `zipfile` / `xml.etree.ElementTree` で XLSX のセル番地・値・型を直接読んだ（openpyxl は環境に未導入）。文字列は sharedStrings または inlineStr、数値は数値型として識別した。CSV は cp932（Shift_JIS互換）で読み、以下ではヘッダーを含む1始まりの行番号と、A＝地域、B＝前年度末、C＝新規、D＝解除、E＝本年度末という列位置を使う。PDF は `pdftotext -layout shiho_keiji_r07.pdf evidence/shiho_keiji_r07.txt` で抽出した。

## Q1

**判定：判定不能。** 「当年」の意味で結論が変わる。令和8年版についての二つの記述は確認できたが、旧版について「当年」が刊行年なのか、その版の最新の統計対象年なのかが指定されていない。

**確かめた箇所と値：** 3ファイルともシートは `参考資料2-13表`。

| ファイル | （1）の最終年行 | （2）の最終年行 |
|---|---|---|
| hakusho_r6_sanko2.xlsx | A23＝令和5年、B23:AV23に47都道府県の値 | A48＝令和5年、B48:AV48に値 |
| hakusho_r7_sanko2.xlsx | A24＝令和6年、B24:AV24に値 | A50＝令和6年、B50:AV50に値 |
| hakusho_r8_sanko2.xlsx | A24＝令和6年、B24:AV24に値 | A51＝令和7年、B51:AV51に値 |

令和8年版の（1）はA25が注記、A26が出典、A28が（2）の見出しであり、（1）に令和7年行はない。例えば北海道の値はB24＝976人、（2）の令和7年B51＝17.37065630792517（保存値）。

**別の説明：** 旧版も両区分の末尾は刊行年の前年である。したがって「当年＝刊行年」なら旧版部分は資料と矛盾し、「当年＝最新の統計対象年（令和5・6年）」なら全体が一致する。令和8年版A25・A53は発見された都道府県別の計上、A52は死亡率が人口10万人当たりであることを説明するが、年行の差の理由は説明しない。

**言い過ぎ：** 「旧版は令和6年版が令和5年、令和7年版が令和6年まで両方にある」と年を明記すれば曖昧さがなくなる。令和8年版の行欠落の原因や意図は資料から確定できない。
