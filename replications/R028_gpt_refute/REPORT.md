## 抽出・照合の要点

PDFは `pdftotext -layout` で抽出し、フォームフィード（`\f`）で分けてPDF頁を1から数えた。頁内の表の行・列はレイアウトを保持した出力で照合した。正誤表の項目数は `^\s*ページ\s+(\d+)\s*ページ` に一致する見出しを数えた。全体版8冊の26,185の検索には、各頁をNFKCで正規化し、カンマなし、空白入り、万表記も含む次の正規表現を使った。

```python
re.search(r"(?<!\d)(?:2\s*万\s*6|2\s*6)\s*,?\s*1\s*8\s*5(?!\d)", page)
```

HTMLはPythonの `HTMLParser` でタグを外し、`script` と `style` の内容を除いてテキストを抽出した。各フォルダの `*.html` を再帰的に読み、次の正規化を施して値と前後の語で検索し、ヒットした箇所の年次・対象・節を照合した。欠落の確認には訂正前後の数値と「生活環境の調整の開始件数」などの対象語を使った。資料の事実認定には配布ファイルを使用した。

```python
normalized = re.sub(r"\s+", "", unicodedata.normalize("NFKC", extracted_text))
```
