# 主張の検証結果

このフォルダ内の写しだけを根拠とした。PDFの頁は先頭を1頁とするPDF頁番号（総務省資料は印字頁とも一致）。HTMLは本文とリンク一覧の両方を確認した。「ない」は、指定資料・指定欄の範囲での不存在を意味する。

抽出はPDFに `pdftotext -layout`、HTMLにPython標準の `HTMLParser` によるタグ除去・リンク抽出、Excelに `zipfile` と `xml.etree.ElementTree` によるセル抽出を用いた。Excelのふりがな要素は表示文字と区別して読んだ。再抽出手順は [evidence/reproduce.sh](evidence/reproduce.sh)、コードは [evidence/extract.py](evidence/extract.py)。抽出全文を evidence/ に、検索結果・頁と計算の要点を [checks.txt](evidence/checks.txt)、Excelのセルを [hanzai_cells.txt](evidence/hanzai_cells.txt) に保存した。外部のリンク先は検証範囲に含めていない。

## Q3

**判定：支持**

### 確かめた箇所と値

`r06_2-5-1_jokyo.pdf` 3頁（8）「児童生徒性暴力等に関する刑事告発の状況」の件数欄を確認した。

| 表の項目 | 読んだ値 |
|---|---:|
| 告発した、または刑事手続きがとられている、またはその他の理由で捜査機関が情報を把握しているもの | 90件 |
| うち教育委員会が告発したもの | 44件 |
| うち捜査機関から教育委員会等へ情報提供があったもの又は他の者が告発を行ったもの | 46件 |
| 犯罪には当たらないと判断したため、告発しなかったもの | 6件 |
| 被害者やその保護者が望まなかったため、告発しなかったもの | 22件 |
| その他 | 16件 |

44＋46＝90。内数を重ねずに90＋6＋22＋16＝134件。1頁（1）の児童生徒性暴力等の総計134人と**数値は一致**する。

### 別の説明

90件は教育委員会が告発した件数そのものではなく、刑事手続き中や捜査機関による情報把握も含む。46件の説明にも「他の者が告発を行ったもの」が含まれる。また6件は「犯罪には当たらないと判断したため」という告発しなかった理由の集計であり、裁判所の判断や無罪判決の件数とは記されていない。

### 言い過ぎの指摘

「計が134人と一致」は数値の一致として支持する。ただし（8）の単位は「件」で、（1）は被処分者の「人」。同一人物・同一事件の対応や重複処理を説明する注記はこの表にはなく、一人につき厳密に一事件だったことまで証明するものではない。「教育委員会が90件告発した」「134人全員の刑事犯罪が確定した」とするのは誤り。

## Q4

**判定：反証**

### 確かめた箇所と値

`pages/1411820_00009.htm` の資料一覧・全リンクに「懲戒処分の公表に関する取組状況一覧」はない。2-6として実際に載るのは「その他の服務違反等に係る懲戒処分等の状況一覧（教育職員）」で、2-7は「懲戒処分に関する処分基準の内容（令和7年10月1日現在）」。この掲載内容は「載っている」という主張と矛盾する。

### 別の説明

`pages/1411820_00007.htm`（令和4年度）には、公表の取組状況を含む一覧が2-6として載る。年度や資料番号を取り違えた可能性がある。令和6年度にも懲戒処分の統計・処分基準は掲載されているが、主張の資料とは異なる。

### 言い過ぎの指摘

当該結果ページへの掲載という主張は誤り。ただし、この写しでの非掲載から他のページ・別媒体での不存在までは言えない。

## Q5

**判定：反証**

### 確かめた箇所と値

`jinji_R6_shiryo2.pdf` 1頁の処分事由欄はQ2に列挙した8区分であり、「わいせつ行為」という区分はない。公務外非行関係の例示は「窃盗、暴行等」。注1にあるのは「処分事由にセクシュアル・ハラスメントを含むものは46人」で、これも「わいせつ行為」という行区分ではない。

### 別の説明

性的な非違行為に関する情報が一切ないわけではなく、注1はセクシュアル・ハラスメントを別途集計している。文科省の `r06_2-5-1_jokyo.pdf` 1頁には「不同意わいせつ」等の定義があるため、機関・資料・分類と注記を区別する必要がある。

### 言い過ぎの指摘

指定した人事院資料2にその区分があるという主張は誤り。区分がないことから、わいせつ行為の処分者が0人だと結論することもできない。

## 全体の要約

Q1・Q2・Q3は支持、Q4・Q5は反証。
Q3は134という数値が一致するが、刑事告発状況の「件」と被処分者の「人」は区別が必要。
資料の非掲載・独立区分の不在は、非掲載の動機や事案の不存在を証明しない。
