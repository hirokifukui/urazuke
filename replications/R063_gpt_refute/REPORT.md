# 公表資料に基づく主張の検証

資料の事実は提供フォルダ内で確認した。PDFは `pdftotext -layout` で再抽出し、改頁ごとに表と注を確認した。頁は原則としてPDFの先頭から数え、紙面の頁番号が異なる箇所は併記した。Excelは `openpyxl.load_workbook(data_only=True, read_only=True)` でセルを読み、CSVは Python の `csv.reader` で読み取った。版の照合には取得元URLを記録した MANIFEST と資料の表題を使った。算術も Python で再計算した。

## Q2　合同概要の旧体制28.6%

**判定：反証。** 合同概要の旧実施体制は **26.6%**。主張の28.6%と矛盾する。

**確かめた箇所と値**　`moj_yakubutsu/gaiyou_joint.pdf` p.1刑事施設欄の棒グラフは旧26.6%、新20.9%、差5.7ポイント。同欄の注は旧593人・新742人とする。`moj_yakubutsu/kyosei_report.pdf` p.13（紙面12）表4の該当セルも158/593人と155/742人で、主張後半の26.6%、20.9%と一致する。表8と注21の値、有意性、参考系列のセルおよび出典の確認範囲はQ1のとおり。28.6%を使うと概要の図にある5.7ポイント差も再現できず、7.7ポイントになる。

**別の説明**　報告書の注22には、属性調整後の旧31.7%、新23.5%という別集計がある。注21の旧21.8%は受講者に限った率である。各数値を読む際は母集団を確認する必要がある。

**言い過ぎの指摘**　旧新の5.7ポイント差は指導対象者全体の比較。受講の効果をその差で表すには、受講率の変化なども考慮する必要がある。受講の有無の比較については注23が検定力の低さを指摘している。

## Q3　保護観察のマッチング後に残る差

**判定：支持。**

**確かめた箇所と値**　`moj_yakubutsu/hogo_gaiyou.pdf` p.1「効果検証の概要」は「受講群と非受講群の属性や特性等が等質となるように抽出した2,812名」と記載。`moj_yakubutsu/hogo_report.pdf` p.8（紙面7）の傾向スコア算出変数(a)〜(q)には、事件種別と保護観察期間は含まれない。「本件の言渡し刑期」は算出変数に含まれる。p.5（紙面4）表1の抽出前は受講2,386人、非受講2,275人。p.12（紙面11）は抽出後を各1,406人と記載する。

| 項目 | 表1からの抽出前の人数・割合（受講、非受講） | 非受講が高い幅 | 抽出後の人数の範囲（受講、非受講） | 抽出後の差の下限 |
|---|---|---:|---|---:|
| 全部実刑者（仮釈放者） | 878人（36.8%）、2,215人（97.4%） | 60.6ポイント | 0～878人、1,346～1,406人 | 33.3ポイント |
| 当初の保護観察期間が6月以内 | 30＋214＝244人（10.2%）、1,170＋993＝2,163人（95.1%） | 84.9ポイント | 0～244人、1,294～1,406人 | 74.7ポイント |

期間の集計は表1の「3月以内」と次の「6月以内」の行を合算した。抽出前の該当人数を `k`、群の総数を `n` として、Python で下限 `max(0,k-(n-1406))` と上限 `min(k,1406)` を計算し、`100*(非受講の下限-受講の上限)/1406` を求めた。付録1の表ア（p.35）の抽出後標準化差は17項目とも0.1未満で、最大0.032は入所度数と覚醒剤取締法違反の2項目。

**別の説明**　報告書 p.6（紙面5）と注5・6では、当初の保護観察期間が6月**未満**だと受講を特別遵守事項に定めないことや、執行猶予に伴う保護観察期間は1年以上であることを説明している。p.20（紙面19）も、事件種別の偏りと統制の限界を明記する。表アは交互作用項の掲載を省略している。

**言い過ぎの指摘**　抽出後欄は人数の上下限であり、実際の内訳は表アからは読めない。6月未満の受講指定条件と、表1の「6月以内」の集計範囲は異なる。統計の一般論として、属性の偏りの方向だけでは再犯率の比較に与える影響の方向は決まらない。

## Q5　性犯罪者処遇プログラムの0.67倍

**判定：支持。**

**確かめた箇所と値**　`moj_sexoffender/001466396.pdf` p.1結果欄は「受講群の再犯率は非受講群の0.67倍に抑えられた」と記載。`moj_sexoffender/001455506.pdf` p.5（紙面4）表4の観測期間最終日の性犯罪再犯率は、受講15.1%、非受講26.2%、対象計1,198人。表示値の比は Python で `15.1/26.2 = 0.576336…`（約0.58）。同頁表5の多変量解析で受講の有無のハザード比は1.485（95%信頼区間1.101–2.004）。p.4（紙面3）本文が非受講を再犯の予測要因とする向きを示しており、逆数 `1/1.485 = 0.673401…` は小数第2位で0.67に一致する。

**別の説明**　概要は再犯リスクの高低を統制した比較も記載している。報告書の表5は受講の有無に加え、RAT得点を用いるCox回帰。表4は生存曲線による観測期間末の累積再犯率を並べている。この違いで二つの比の併存を説明できる。概要に0.67の計算式は示されておらず、表5との対応は値と分析記述からの推定である。

**言い過ぎの指摘**　統計の一般論として、ハザード比はある時点まで再犯していない人の瞬間的な発生率の比で、累積再犯率の比とは尺度が異なる。小さい値を選んで効果が大きいと評価することはできない。報告書は性犯罪の再犯について効果を示唆し、全再犯については比例ハザード性の仮定を満たさず同じ検証を行っていない（p.4–5、注11）。
