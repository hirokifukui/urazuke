## 資料と方法

`hanzai_hakusho/` 内の資料のみを使用した。各 `MANIFEST.tsv` の取得元URLと、それが指す `index/mokuji.html` の版名を照合した。以下のExcelファイル名は、特記のない限り各版の `zuhyo/` 以下を指す。PDFの頁は誌面の頁番号を用い、PDFファイル内の通し頁は表紙から数えた。

| 版 | 使用したフォルダ |
|---|---|
| 令和元年 | `66_20261116T095154Z` |
| 令和2年 | `67_20261116T094520Z` |
| 令和3年 | `68_20261116T085457Z` |
| 令和4年 | `69_20261116T085457Z` |
| 令和5年 | `70_20261116T073025Z` |
| 令和6年 | `71_20261116T090659Z` |
| 令和7年 | `72` |

Excelは Python の `openpyxl.load_workbook(read_only=True, data_only=True)` でセル値を抽出し、表示精度に合わせた丸めは比較後に行った。PDFは `pdftotext -layout` の出力を改頁文字で分割し、表題・行・列を照合した。同じ版の別取得フォルダにある `zuhyo/`・`shiryo/` のExcelは SHA-256 で照合し、すべて対応する採用ファイルと同一だった。

## 集計の再現要点

```python
# rows = list(sheet.values)。スライスは0始まり、本文のセル番地は1始まり。

```
