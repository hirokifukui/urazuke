# 課題：主張の検証（反証の試み）

このフォルダには、日本の法務省が公表した資料の写しがあります。
- hakusho/r03〜r07：犯罪白書 令和3年版〜令和7年版の図表 Excel（ファイル名は各版の図表番号。図表番号は版ごとに振り直されることがある）。一部の版は PDF のテキスト（pdftotext -layout）と正誤表を含む。
- moj/：法務省保護局の資料（001318218＝令和2年3月版の分析、001466396＝その概要、001322889＝平成24年版の分析）。PDF とテキスト。

以下の12の主張は、ある検証者が書いたものです。**正しいものも、誤っているものも含まれています。**あなたの役割は、各主張を資料だけに基づいて独立に確かめ、誤りがあれば見つけることです。検証者の結論に合わせる必要はありません。

## 判定の規則（先に固定する。これ以外の判定はしない）
各主張について、次の3つのどれか1つを選ぶ。
- **支持**：主張の中の数値・事実を、資料の該当箇所（ファイル名・シート名・セル、または PDF テキストの行）で自分で確かめ、すべて一致した。
- **反証**：主張の中の数値・事実の少なくとも1つが、資料の該当箇所と矛盾する。矛盾する箇所と値を示す。
- **判定不能**：資料に確かめる材料がない、または解釈によって結論が変わる。何が足りないかを書く。

さらに、各主張について次を書く。
1. 確かめた箇所（ファイル・シート・セル／行）と、読んだ値。
2. 主張を弱める別の説明（誤りではなく正当な理由で説明できる可能性）があれば、それを挙げる。
3. 主張の言い方が、資料が示す以上のことを言っていないか（言い過ぎ）。

計算はコードで行い、使ったコードの要点を残す。資料にないこと（推測、記憶）で判定しない。

## 主張
- **P01** 犯罪白書 令和5年版の 2-2-3-1図（Excel）で、令和3年（2021年）の「勾留関係_認容（D）」は 83,315 である。
- **P02** 令和3年版犯罪白書の正誤表は、2-5-3-6表 Excel の「保護観察付全部執行猶予者」の総数を 7,411 から 7,410 に、3-2-5-6表 Excel の「保護観察処分少年」の総数を 8,114 から 8,116 に訂正すると告知している。しかし、このフォルダの令和3年版 Excel は、どちらも訂正前の値（7,411、8,114）のままである。
- **P03** 保護局 令和2年3月版の分析の表1（号種別人数）は、行と列の合計が合わない。
- **P04** 令和4年版の 2-2-3-1図（Excel）で、令和3年（2021年）の「勾留関係_認容（D）」は 83,315 であり、正しくは 83,815 である。根拠：同じ版の 2-2-3-2表と PDF の 2-2-3-2表が 83,815、令和5年版以降の 2-2-3-1図が 83,815、同じ行の勾留請求率（94.329％）は 83,815 から計算した値である。
- **P05** 保護局の概要（001466396）の「受講群の再犯率は非受講群の0.67倍」の 0.67 は、分析（001318218）の表5のハザード比 1.485 の逆数であり、再犯率の比ではない。表4の再犯率の比は約0.58である。
- **P06** 2-2-3-2表の Excel で、機械判読用シートの68〜104行目に、表の本体とは別の37行が残っている。値は令和2年のもので、令和3年版・令和4年版・令和5年版にあり、令和6・7年版にはない。
- **P07** 保護局 令和2年3月版の分析では、非受講群297名のうち226名（約76％）が「保護観察期間3月未満」の仮釈放者である。また、保護観察付執行猶予者の割合は受講群約35％・非受講群約15％で、Cox 回帰の変数は受講の有無と RAT 得点だけである。
- **P08** 令和6年版・令和7年版の 5-4-4表③（全部執行猶予の取消し）の Excel のうち、令和6年版は1989〜2016年の「計（B）」が表①の値の写しになっていて、令和7年版で直っている。
- **P09** 犯罪白書の覚醒剤の密輸入の押収量（4-2-2-2表）は、令和3年・令和4年・令和5年の値が、それぞれ翌年の版で上方に改訂されている（例：令和5年の総数 1,978kg → 2,246kg）。
- **P10** 令和4年版では、1-1-1-1図の刑法犯の検挙人員などが2002〜2014年について前の版より小さく改訂された（例：2002年 347,880 → 347,558）が、年齢層別・男女別の内訳の図（1-1-1-5図、3-1-1-4図）では同じ年の改訂は令和5年版で行われた。
- **P11** 保護局 令和2年3月版の分析は、すべての再犯について「比例ハザード性の仮定を満たしていなかった」ため検証しなかったと書いている。しかし、表4で使っている log-rank 検定は比例ハザード性を前提とせずに実施できる。
- **P12** 保護局 平成24年版の分析の表3（罪種別）の人数の合計は 4,185 で、対象全体の 4,248 より 63 名少なく、その理由は書かれていない。
