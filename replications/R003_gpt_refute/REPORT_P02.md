## 探索・再現方法

拡張子を `.txt` に限定せず、フォルダ内の全ファイルを列挙した。資料は Excel 43件、PDF 3件、HTML 1件とテキストを含む。Excel は全ブックの全シートを `audit/check.py` の `sheets()` で読み、PDF は `pdftotext -layout` で抽出し、HTML・テキスト・Markdown・コード・JSON はテキストとして検索した。生成済み `.pyc` は資料ではないことを確認し、根拠には用いていない。課題文や既存 REPORT.md も資料の独立した裏付けには用いていない。

検索時は `unicodedata.normalize('NFKC', text)` で全角数字・記号を正規化し、ハイフンの表記ゆれも吸収した。候補発見後は HTML の原文と表の「誤／正」の対応を直接確認した。例えば「３－２－５－６」は正規化後に「3-2-5-6」となる。Excel の読出しは次の要領で行った（再計算は不要）。

```python
import sys
sys.path.insert(0, 'audit')
from check import sheets

for path, target_sheet, address in [
    ('hakusho/r03/2-5-3-6.xlsx', '2-5-3-6表（R２）', 'F6'),
    ('hakusho/r03/3-2-5-6.xlsx', '3-2-5-6表（R２）', 'E6'),
]:
    rows = dict(sheets(path))[target_sheet]
    cells = {key: value for row in rows for key, value in row.items()}
    print(path, target_sheet, address, cells[address])
# F6: 7411、E6: 8114
```
