# 主張の検証（フォルダ内の資料のみ）

判定は主張全体について行った。部分的に確認できても、残りが資料から確定できない場合は「判定不能」とした。特に、数値の一致と、その数値が作られた経緯の証明を区別した。外部資料・記憶による補完は行っていない。

根拠の行番号は同梱 `.txt` の先頭を1とした物理行番号（空行を含む）。Excel は ZIP 内の XML を直接読み、シート名・セル番地・保存値を取得した。以下の `r03`〜`r07` は `hakusho/` 配下。セル範囲を示す場合も、年度の対応と代表値を併記した。

## P05

**判定：判定不能**

- **確かめた箇所と値：** `moj/001466396.txt` 38〜41行に「受講群の再犯率は非受講群の0.67倍」。`moj/001318218.txt` 表5、179〜183行はハザード比1.485（受講の有無）、1.442（RAT）。110〜111行では「受講していないこと」が再犯を予測すると記述。表4、163〜170行の観測期間最終日の再犯率は受講群15.1％、非受講群26.2％。

- **別の説明：** 概要は28行でリスクを統制した比較と説明しているため、調整後の比較指標を平易に「再犯率」と表現した可能性がある。
- **言い過ぎ：** 資料には0.67の算出式や表5から算出したという明示がない。「逆数と一致する」は確認できるが、「逆数である」という算出経緯の断定までは確定できない。また「再犯率の比ではない」を表4以外のあらゆる調整後指標にも広げる根拠はない。数値の対応のみを述べる解釈なら支持できるため、主張全体は判定不能とした。

## 計算・再現方法

作成したコードは [audit/check.py](audit/check.py) と [audit/calculate.py](audit/calculate.py)。実行はフォルダ直下から次のとおり。

```sh
python3 audit/check.py
python3 audit/calculate.py > audit/results.txt
```

`check.py` は標準ライブラリの `zipfile` と `xml.etree.ElementTree` で、workbookの関連付けからシートを特定し、共有文字列とセル保存値を読み出す。Excelを再計算したものではない。全抽出結果は [audit/cells.json](audit/cells.json)、[audit/cells.txt](audit/cells.txt)、集計結果は [audit/results.txt](audit/results.txt)。[audit/inspect.py](audit/inspect.py) は確認用の抜粋を出力する。

計算の要点は、P03の縦横加算、P04の率の再計算、P05・P07の除算、P06の37×7セル比較、P08の28年の表間比較と内訳加算、P09の重複しない4形態の加算、P10の年度を合わせた比較、P12の加算・差分である。P06のセル差は数値の差であり、年度の由来を証明するものではない。P08の一致も編集操作そのものを証明しない。
