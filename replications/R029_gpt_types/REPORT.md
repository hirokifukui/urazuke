# 引用の型の判定

| 組 | 型 | 根拠 |
| --- | --- | --- |
| C01 | T4 | 「同15.3%増」「4年連続で過去最高」と年をまたいで比較しているが、令和6年から相談の有無を問わず全件を計上するようになったという注がない。 |
| C02 | T0 | 「ストーカー規制法違反の検挙」の1,081件が一致する。前年比53件増と過去最多かどうかは、提示された元の文だけでは照合できない。 |
| C03 | T1 | 2024年の小中高生の自殺者数が、元の文では529人、引用では629人になっている。 |
| C04 | T0 | 2025年の小中高生の自殺者数は538人で一致する。学生全体の1,082人と過去最多かどうかは、提示された元の文だけでは照合できない。 |
| C05 | T0 | 令和5年と2023年は同じ年で、ストーカー規制法違反の検挙1,081件も一致する。 |
| C06 | T3、T4 | 「処遇効果が示唆された」が「一定の処遇効果が認められた」に強まり、「刑事施設及び保護観察所における」という適用範囲も省かれている。 |
| C07 | T0 | 受講群15.0％、比較対照群22.5％が一致し、「再犯可能性が低い」は0.75倍と同じ方向の記述である。0.75倍を再犯率として用いてはいない。 |
| C08 | T3 | 「処遇効果が示唆された」が「一定の処遇効果が認められた」に強まっている。 |

| C10 | T0 | 再犯率は27.3％と38.0％（引用では38％）で一致し、見出しの「再犯リスクが低下」は元の「再犯可能性は0.79倍に抑えられた」に対応する。統計的な裏付けが得られなかった違反類型も引用の本文に明記されている。 |
| C11 | T0 | 「およそ14％（13.8％）」と「約14％」は同じ丸め値で、約1,300人という推計も一致する。「2015年6月時点」は数値の基準時点として書かれており、元の文の「平成28年1月」からは照合できない。 |
| C12 | T1 | 元の確定値214,843件が、引用では214,483件になっている。 |

| C14 | T4 | 「いずれも00年の同法施行後、最多」と計上方法の変更をまたいで比較しているが、令和6年から全件計上になったという注がない。 |
| C15 | T0 | 性犯罪再犯の15.0％と22.5％が、元の文と同じ順序で示されている。追加研究が必要という一文は、群別の再犯割合の記述と両立する。 |
| C16 | T0 | 確定値214,843件と速報値219,170件が一致し、差の4,327件も両値の差と一致する。 |
| C17 | 判定不能 | 群別の15.1％と26.2％は一致するが、引用の「再犯率」が元の「性犯罪の再犯率」の略記か、全再犯を指すかは提示文だけでは特定できない。 |
| C18 | T4 | 元の文には強制わいせつや迷惑行為防止条例違反などで統計的な裏付けが得られなかったとあるが、引用はその限定を添えずに効果を伝えている。 |
| C19 | T2 | Coxモデルによる「再犯可能性」の0.79倍を、「再犯率」の比として書いている。 |
| C20 | T2、T3 | 別々の群の38.0％と27.3％を、受講者の再犯率が38.0％から27.3％へ低下したと書いている。元の文は群別の率を示しており、引用は「効果はある」と断定している。 |
| C21 | T3 | 「処遇効果が示唆された」が「一定の処遇効果が認められた」に強まっている。 |

| C23 | 判定不能 | 元の文には全国の人数や都道府県別の減少順位を照合できる値がなく、回答率に関する注もない。挙げられた各県の特定年の落ち込みだけでは、引用の全国推移や順位の違いは判定できない。 |

## 全体の要約

値の相違は2組、量の置き換えは2組、言い方の強まりは4組、限定の脱落は5組だった（複数該当を含む）。  
T0は9組、判定不能は3組で、T5に該当する組はなかった。
