## Q1 — 判定不能

**確かめた箇所と値**

| 資料と位置 | 読んだ値・記述 |
|---|---|
| `moj_kensho2__sib_report.pdf` PDF 15頁（紙面13頁）、図表7 | 再処分率の評価対象は2021～2023年度の支援対象者の合計。対照群は379人。 |
| 同 PDF 16頁（紙面14頁）、評価結果「③再処分率」 | 再非行・再犯により保護処分または刑事処分を受けた人の割合は支援対象者5％、比較対照群8.7％。 |
| 同 PDF 17頁（紙面15頁）、図表8 | 再処分率の結果欄は「5/8.7」、成果欄は57％。これは両群の率の比（約57.47％）。 |
| 同 PDF 26頁（紙面24頁）およびPDF 8頁（紙面6頁）、`moj_kensho2__sib_gaiyou.pdf` PDF 1頁「対象者」 | 事業の支援対象者は29人。 |

SIB総括PDF全26頁と概要PDF全1頁の範囲では、支援対象者側の再処分人数と5％の算出に実際に用いた分母の明記を確認できなかった。対照群側も再処分人数33人の明記は確認できなかった。379人を分母とし、小数第1位まで通常の四捨五入をしたと仮定すると、8.7％になる整数は33人だけ（33 ÷ 379 ≈ 8.707％）。Q1の「33 ÷ 379」を丸めからの逆算として読むと整合するが、実際の再処分人数を資料で確かめた値として読むと、算出内訳が足りない。

**別の説明**  
同PDF 16頁（紙面14頁）注10では、別指標のYNPSスコアについて、測定面談前に支援が終了した少年を除いて20人を測定したと明記する。同じ事業でも指標によって集計対象が異なり得る例であり、この20人が再処分率の分母だったと判断できる記述は見当たらなかった。

**言い過ぎの指摘**  
29人を分母にすると、全整数人数を試しても、ちょうど5％になる人数も、整数％に四捨五入して5％になる人数もない。1人は約3.4％、2人は約6.9％で、表示値8.7％との差はそれぞれ5.3、1.8ポイント。いずれも仮定上の差であり、分母の明記がないため、実際の人数を1人か2人に絞れない。公表値では支援対象者側の率が低い。総括PDF 25頁（紙面23頁）「評価方法」は事業以外の要因を挙げており、この差だけから事業による低下幅は確定できない。

## Q2 — 反証

**確かめた箇所と値**  
`moj_kensho2__sib_report.pdf` PDF 8・26頁（紙面6・24頁）と `moj_kensho2__sib_gaiyou.pdf` PDF 1頁「対象者」はいずれも事業の支援対象者を29人と記載する。冒頭の31人は資料と矛盾し、主張の後段の29人とも食い違う。PDF 15・16頁（紙面13・14頁）の379人、5％、8.7％と、29人を仮定した計算はQ1のとおり。

**別の説明**  
31人を仮の分母として全整数人数を試しても、ちょうど5％または整数％への四捨五入で5％になる人数はない。この算術上の性質は29人と共通する。資料が示す事業全体の29人と、再処分率の算出に実際に使った分母は区別する必要がある。

**言い過ぎの指摘**  
31人を事業の支援対象者数として使う根拠はない。5％と8.7％の大小は公表値から読めるが、33人は丸めを仮定した逆算値で、5.3・1.8ポイントも実際の再処分人数が確定した差ではない。

## 抽出・計算の要点

4 PDFを `pdftotext -layout` で抽出し、Pythonでフォームフィードごとに分割して通し頁を照合した。Excelは `openpyxl.load_workbook(path, read_only=True, data_only=True)['1']` で読み、上記セルを取得した。照合に用いた計算の要点を示す。

```python
from decimal import Decimal as D

# n人のうちk人。表示桁への丸めは検証用の仮定。
for n, target, digits in [(29, D(5), 0), (31, D(5), 0), (379, D("8.7"), 1)]:
    print(n, [k for k in range(n + 1) if round(D(100) * k / n, digits) == target])
# 29 [], 31 [], 379 [33]
print(100 * D(5) / D("8.7"))
print([D("8.7") - round(D(100) * k / 29, 1) for k in (1, 2)])
# 約57.47、[5.3, 1.8]
print(sum([2292979, 536575]), sum([3537, 12582, 252879, 2560556]))
print(2829554 - 2829544, 3027612 - 2829554, D("78.7") - D("74.0"))
# 2829554, 2829554
# 10, 198058, 4.7
```
