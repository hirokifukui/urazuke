## 抽出・計算の要点

PDFは各ファイルに `pdftotext -layout` を実行し、Pythonで `text.split("\f")` を1から数え、本文の頁番号と表の列見出しを照合した。HTMLはPython標準の `HTMLParser.handle_data` で本文とリンクの表示文字列を抽出した。表番号は `unicodedata.normalize("NFKC", text)` を用い、空白を許容して検索した。Q8の概要は抽出順と各段の列位置を照合した。再計算の主要部分は以下のとおり。Cox回帰の指数変換とMantel–Haenszel推定・対数尺度の信頼区間は、一般的な統計の性質を用いた。

```python
from math import exp, log, sqrt

exp(0.12), log(0.89)
[100 * a / n for a, n in [(34, 57), (30, 81), (34, 81),
                          (81, 1444), (82, 324), (1, 71), (4, 99)]]
59.6 - 42.0, 100 * (34 / 57 - 34 / 81)
9677 - 8445, 2918 - 2698, 1 + 4, 24 / 38, 58 / 82
6.0 / 9.5, 14.4 / 20.4

# 各層は順に受講群の再犯数・総数、比較対照群の再犯数・総数。
strata = [(105, 480, 25, 73), (194, 653, 23, 92),
          (51, 81, 46, 82), (22, 176, 6, 36)]
total = (394, 1444, 123, 324)
strata.append(tuple(t - sum(col) for t, col in zip(total, zip(*strata))))
crude = (394 / 1444) / (123 / 324)
r = sum(a * m / (n + m) for a, n, c, m in strata)
s = sum(c * n / (n + m) for a, n, c, m in strata)
mh = r / s
variance = sum((n * m * (a + c) - a * c * (n + m)) / (n + m)**2
               for a, n, c, m in strata) / (r * s)
ci = tuple(exp(log(mh) + z * sqrt(variance)) for z in (-1.96, 1.96))
```
