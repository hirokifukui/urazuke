# H009 医療観察法の統計 — 検査の計画と判断の基準（データを見る前に固定）
作成：2026-11-17 JST（医療観察法の統計を一つも開く前に書き、コミットする）
理由：運営者の業務に関わる対象（進め方 §2）。運営者は司法精神医学の臨床・鑑定に携わり、医療観察法の対象者の処遇と利害を共有しうる。
このため、何を検査し、何を記録にするかを、結果を見る前にここで固定する。記録には「運営者の業務に関わる対象」と明記する。

## 対象とする資料
1. 保護統計年報（e-Stat）のうち、医療観察法による生活環境の調査・調整、精神保健観察の表（直近年と、その累年表）
2. 厚生労働省「心神喪失者等医療観察法」の公表資料（指定入院医療機関の整備状況・入院処遇の状況など、機械判読できる表）
3. 司法統計年報（最高裁）のうち、医療観察事件の表（ある場合）
4. 犯罪白書の医療観察制度の節（令和7年版）

## 行う検査（これ以外の観点で記録を作らない）
- L1：表の中の恒等式（内訳の和＝総数、前年からの繰越＋開始−終了＝年末現在、男＋女＝総数、施設の和＝全国）
- 版間：同じ年の値が、別の年の版・累年表で違うか（説明の注があれば記録にしない）
- 形式間：同じ表の Excel と PDF で値が違うか
- 他の資料：犯罪白書の値と、出典として示された統計（保護統計・司法統計・厚労省資料）の値が違うか

## 記録にしないもの（固定）
- 制度の効果、運用の当否、病床の過不足など、評価や意見にあたるもの
- 定義の違いが注に書かれている差（作業ノートに「説明のある違い」として残す）
- 四捨五入の範囲に収まる差

## 判断の基準
- 恒等式が成り立たない、または二つの公式の値が違う → 不整合（どちらが正しいか決められない場合）。正しい値を独立した二つ以上の資料で示せた場合だけ誤り。
- 影響は METHODS の基準どおり（大＝結論・指標・全国計、中＝値の食い違い、小＝副次的なファイルだけ）。迷ったら小さいほう。
- 記録にした項目は、R009 の事前登録（H010）に入れ、別系統の反証にかける。R009 の判定は事前に決めた基準どおりに反映する（支持→別系統で支持、反証→撤回か修正、判定不能→機械検証のみ）。
- 検査の結果が 0 件でも、そのまま作業ノートに書き、記録を作るために観点を足さない。
