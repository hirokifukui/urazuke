# H040 記録の候補3件（SH-C1・ST-D1・SH-A2）

2026-11-18 作成。反証の回（R048、GPT）より前に書く。

## 主張
- SH-C1：再犯防止推進白書 平成30年版・令和元年版（印刷80頁）の「7.7ポイント低い…一定の再犯抑止効果が認められている」は、2012年の分析の「全ての犯罪」の推定再犯率の差。性犯罪の再犯では効果が確認されず、分析は精度の限界を書く。白書の段落はこの限定を書いていない（型 T4 に当たる）。
- ST-D1：警察庁の令和6・7年の対応状況は DV 相談等件数を「ＤＶ防止法施行後最多」とするが、注3 のとおり令和6年4月から計上の範囲が広がり、新たに計上した件数は示されていない。
- SH-A2：再犯防止推進白書 令和5年版の正誤表の38頁脚注（前年：76庁→75庁）が、全体版 PDF と Web 版に反映されていない（SH-A1 と同じ型）。

## 反証の条件
- SH-C1：白書の同じ段落か近くの注に、全ての犯罪の再犯であること・性犯罪再犯の結果・精度の限界のいずれかが書かれている。または 7.7ポイントが別の比較の差である。
- ST-D1：同じ公表の資料に、新たに計上した脅迫の件数か、範囲を揃えた件数がある。
- SH-A2：全体版 PDF か Web 版のどちらかが訂正後の値になっている。
