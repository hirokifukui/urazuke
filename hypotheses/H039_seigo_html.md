# H039　正誤表の訂正が HTML 版に入っているか（再犯防止推進白書、2026-11-18、照合の結果を見る前に固定）

## 位置
- 記録 SH-A1 の確認の途中で、令和2年版の HTML 版の本文が正誤表の訂正前の値（2万6,184人）のままであることが分かった。同じことが他の訂正・他の版でも起きているかを、機械で照合する。
- 対象：HTML 版がある 2020〜2025年版（令和2〜7年版）。平成30年版・令和元年版は HTML 版が見つからない（URL の候補が 404）。正誤表は各版の seigo_*.pdf。

## 手順（checks/saihan/c602_seigo_html.py）
- HTML 版の目次から全ページを取得し、正誤表の各訂正の「誤」「正」の文字列が、同じ版の HTML 版のどのページにあるかを数える。数値は「26,184」と「2万6,184」の両方の書き方で探す。
- 「誤」だけがある：訂正が HTML 版に入っていない候補。「正」だけがある：入っている。どちらもない：図表が画像であるなどで照合できない（照合できないと書く）。どちらもある：文脈を人が読まずに、該当ページの前後を記録に引く。
- 候補は、記録 SH-A1 に足すか、新しい記録にするかを、反証の回（別系統の判定）で決める。
