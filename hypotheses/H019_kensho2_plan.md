# H019　矯正の就労関係の効果検証と、少年院出院者の学習支援（SIB）の総括の検証計画（2026-11-17）

## この登録の位置
- 資料（data/raw/moj_kensho2/、MANIFEST.tsv）を取得してテキストにした直後、本文を読む前に書いた（分析の前の登録）。
- 少年院の特定生活指導の効果検証は「刑政」誌の掲載だけで公開の PDF がなく、保護観察の飲酒運転防止プログラムは公表された効果検証が見つからなかった。代わりに、同じ型の公開資料（矯正局の効果検証2件、少年院出院者の SIB 事業の総括）を対象にした。

## 調べること（固定）
1. L1・L5：表の合計・構成比、検定統計量と p、効果量を再計算する。
2. L4：概要の数値・文言が本文と合うか。調整前の差を効果として書く箇所がないか。
3. L7：群の作り方（修了者と非修了者、有職と無職、SIB の参加者と比較の相手）、バイアスの統制の方法と範囲。成果指標（再処分率など）の定義と比較の相手。
4. 他資料：本文が引く公表統計（保護統計・矯正統計・犯罪白書）の値と照合できるものは照合する。

## 外れうる予測（反証の条件）
- P1：統計値は再計算と合う。
- P2：概要に、調整前の差や有意でない差を効果として書く箇所はない（前回は外れた）。
- P3：刑務作業の検証は「保護観察終了時の就労状況」と再入率の関連を示すもので、刑務作業そのものの効果は推定していない（予測）。本文が刑務作業の有無・量で比べていれば、この予測は外れる。
- P4：SIB の成果指標（再処分率など）は比較の相手（同時期の非参加者など）を置いていない（予測）。置いていれば外れる。
- 作成者の意図についての仮説は立てない。
