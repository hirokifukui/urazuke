# H011 再犯指標の総点検 — 検査の計画と判断の基準（新しい資料を開く前に固定）
作成：2026-11-17 JST（コミットしてから、新しく取得する資料を開く）
理由：運営者の業務に関わる対象（進め方 §2）。運営者は性犯罪加害者などの治療を行い、再犯の指標は事業の評価と政策の根拠に直結する。

## 既に見たもの（正直に書いておく）
- 再犯防止推進白書の8版、矯正統計年報 表84（帰住先）、保護統計年報 表38、法務省の統計正誤情報は、r03〜r09 で開いて照合済み（results/saihan、results/kyosei）。
- 犯罪白書は令和7年版まで取得済み（results/hanzai_hakusho）。ただし再入率の表は、この点検の観点ではまだ照合していない。
- 今回新しく開くもの：矯正統計年報の再入の表（第64表など、出所年別の再入状況）、犯罪白書の再入率の図表（出所年別 2年以内・5年以内・10年以内）、再犯防止推進白書の成果指標の定義と基準値・実績値の表、保護統計の再処分の表。

## 行う検査（これ以外の観点で記録を作らない）
1. 再計算：白書が載せる再入率（出所年別・出所事由別）を、出典として示された矯正統計の人数（出所人員・再入者数）から計算し直し、丸めの範囲で一致するか。
2. 定義の突き合わせ：同じ名前の指標（「2年以内再入率」など）について、分母（出所年の出所人員か、その一部か）、分子（再入の範囲：刑事施設への再入所か、再犯で検挙か）、追跡期間の数え方が、資料（犯罪白書・再犯防止推進白書・矯正統計）の間で同じか。違う場合、その違いが資料の中で説明されているか。
3. 版間：同じ出所年の同じ指標の値が、白書の版の間で変わっていないか（「2年以内」は追跡が終われば変わらないはず）。変わっていれば、正誤表・注・元の統計の正誤情報で説明されるか。
4. 成果指標の目標と実績：再犯防止推進計画の成果指標（基準値・目標値・各年の実績）が、版の間・本文と資料編の間で同じか。

## 記録にしないもの（固定）
- 指標の選び方・目標の水準・政策の評価についての意見。
- 定義の違いが資料の中で説明されているもの（作業ノートに「説明のある違い」として残す）。
- 丸めの範囲の差。

## 判断の基準
- 再計算が合わない、定義の違いに説明がない、版間の変化に説明がない → 記録の候補。区分は METHODS どおり（不整合／説明のない改訂／欠落／照会事項）。
- 記録の候補は、まとめて事前登録（H014）してから別系統の反証（R010）にかけ、事前に決めた基準どおり反映する。
- 結果が0件でも、そのまま作業ノートに書く。観点を足して記録を作ることはしない。
