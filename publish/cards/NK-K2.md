# NK-K2　認知症スクリーニング検査の平成30年の人数：答弁書は 904名（入所時60歳以上）、再犯防止推進白書は 893人（対象はより広い）。数え方の説明はどちらにもない

- **統計**：認知症スクリーニング検査の平成30年の実施人数（内閣の答弁書 衆質200第64号・再犯防止推進白書 令和4年版 特2-1-4表）
- **区分**：不整合
- **格付け（METHODS）**：A
- **確実さ**：値の食い違いは確定（両資料の原文）／どちらの数え方によるかは要照会
- **確認の状態**：別系統で支持（R075：主張を伏せて原文だけを渡し、GPT・Gemini とも各5回の過半で、同じ年・同じ取組の人数として示され、904 が多く、白書の対象が広く、違いを説明する記述はなく、資料からどちらが正しいか決められない、と答えた。対照（令和2年 930人の一致）は 10回とも正答）
- **結果**：認知症スクリーニング検査の平成30年の人数が、法務省の二つの公表で合わない。内閣の答弁書（衆議院 質問第64号への答弁、令和元年11月15日）は、平成30年に札幌・宮城・府中・名古屋・大阪・広島・高松・福岡の8刑務所に入所した受刑者のうち入所時60歳以上の者 904名に検査を実施し、認知症傾向がある者（得点が基準点以下）は 109名とする。再犯防止推進白書 令和4年版の特2-1-4表は、平成30年の認知症スクリーニング検査実施者を 893人とする（医師による診察 131人、認知症診断者 35人。注は「法務省調査による」）。同じ白書の本文は検査の対象を「入所時の年齢が60歳以上又は…認知症が疑われる者」とし、答弁書の対象（入所時60歳以上の者）を含む広い範囲だが、人数は 11人少ない。どちらの資料にも、数え方の基準（入所の年か検査の年か、年か年度か）は書かれていない。令和2年・3年の値（930人・973人）は犯罪白書 令和3年版・令和4年版の本文と表で一致する。答弁書の 109名（検査で基準点以下）と表の 131人（医師による診察）は別の量として示されている。
