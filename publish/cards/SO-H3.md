# SO-H3　比例ハザード性を理由に、すべての再犯の検証をしていない

- **統計**：法務省保護局 性犯罪者処遇プログラム効果検証（令和2年3月・平成24年）
- **区分**：設計上の問題
- **格付け（METHODS）**：D
- **確実さ**：記述の事実は確定／影響の大きさは要開示
- **確認の状態**：別系統で支持（別系統 R007）
- **結果**：すべての再犯について「比例ハザード性の仮定を満たしていなかった」ため検証しなかったとある。統計手法の一般的な性質として、生存曲線（カプラン・マイヤー法）と log-rank 検定は比例ハザード性を前提にせず出せる（曲線が交差する場合などは検出力に注意を要する）。平成24年版はすべての再犯を報告していた。
