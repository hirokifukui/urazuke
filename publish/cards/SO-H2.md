# SO-H2　号種の偏り（35.4%と15.5%）を Cox 回帰で調整していない

- **統計**：法務省保護局 性犯罪者処遇プログラム効果検証（令和2年3月・平成24年）
- **区分**：設計上の問題
- **格付け（METHODS）**：D
- **確実さ**：記述の事実は確定／影響の大きさは要開示
- **確認の状態**：別系統で支持（別系統 R007）
- **結果**：保護観察付執行猶予者の割合が受講群35.4%・非受講群15.5%と偏るが、公表された Cox 回帰の変数は受講と RAT 得点だけで、号種の調整がない。この偏りが効果の推定をどの向きにどれだけ動かすかは、資料から決まらない。
