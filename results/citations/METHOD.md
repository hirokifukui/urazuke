# 引用の追跡の方法（v0.1）

## 引用の追跡（v0.1、2026-11-18）
- 記録のある資料の数字・結論が、報道・公的文書・論文でどう引かれているかを探す。登録は hypotheses/H034_citations.md、検索語は results/citations/TARGETS.tsv（探す前に固定）。
- 一つの引用を一行（results/citations/citations.tsv）。引用の文は写さず、15字以内の鍵の言い回しと要旨だけを置く。写しは data/raw/citations/（手元のみ）に sha256 を付けて置き、Wayback の有無を記す。
- 型 T0〜T5 は、元の文・引用の文・定義だけを別系統の AI に渡して付けさせる。偽の対照を2つ混ぜ、両方正答の回だけ採る（初回 R029：対照 2/2 正答）。別系統が判定不能とした組は「判定が分かれた」とし、人は判定しない。
- 引いた側の意図・媒体の評価を書かない。照会・訂正の依頼をしない。結果はサイトの「引かれ方」に載せる（2026-11-18、運営者の決定。弁護士の確認は返事待ちで、指摘があれば直す）。
- 2026-11-18（午後）　Perplexity API でも探した（答えの文は公開しない。出てきたページを取得し、写しで引用の文を確かめたものだけを足す。robots.txt で拒否されるページは取得しない）。R030・R031 で型を付けた。元の資料の文には、同じ頁にある定義・調査時期・比較の範囲を含めて渡す（R030 で NK-K1 の定義を渡していなかったため、R031 でやり直した）。
